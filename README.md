# C-Lab Reservation App

Esta aplicación permite a los usuarios agendar una hora para usar el laboratorio de forma sencilla. Está diseñada para facilitar el proceso de reservación y es accesible para cualquier persona que llegue al laboratorio.

## Características

- Reservar horas de uso para el laboratorio.
- Ver la disponibilidad de horarios.
- Interfaz fácil de usar y accesible desde cualquier navegador.

## Requisitos

- Python 3.x
- Streamlit
- Otras dependencias necesarias (como las de Google Calendar API)

## Instalación

1. Clona este repositorio:
    ```bash
    git clone https://github.com/cattgt/c-lab-reservation.git
    ```

2. Instala las dependencias necesarias:
    ```bash
    pip install -r requirements.txt
    ```

3. Ejecuta la aplicación:
    ```bash
    streamlit run app.py
    ```
